# Java Employee Management System

A desktop employee management application built with **Java Swing** and **MySQL**.

The project provides a graphical interface for working with employee records stored in a MySQL database.

## Features

- Add and manage employee records
- Search and filter employees
- Filter by:
  - Name
  - Email
  - Department
  - Salary
  - Age
  - Hire year
- Dynamic department selection
- Display database records in a table
- MySQL database integration

## Technologies

- **Java**
- **Java Swing**
- **JDBC**
- **MySQL**
- **Apache NetBeans**

## Database

The application uses a MySQL database named `new_schema` and works with employee and department data.
